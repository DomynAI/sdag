    Structuring Larger Projects

    When working with larger projects made of many pipelines, it is convenient to set the directory sdag searches pipelines into explicitly. Both flat and src layouts are supported. The only important point is to add __init__.py files to all subfolders in the tree to let sdag treat them as regular, importable packages.

    This example takes advantage of the hello.py module created in the first example:

    hello.py
    from sdag import pipeline, script


@pipeline
def hello_world():
    say_hello(name="sdag")


@hello_world.task(script)
def say_hello(name: str):
    print(f"hello from {name}")

    Flat layout

    Create a <package-name>/workflows directory and an empty __init__.py module inside it. Now, copy the hello.py module from the previous example in the workflows/ folder. Finally, copy the following snippet inside the pyproject.toml file:

    pyproject.toml
    [tool.sdag]
dagdir = "<package-name>/workflows"

    Your project tree should look like this:

    flat layout
    <package-name>
├── pyproject.toml
└── <package-name>
    ├── __init__.py
    └── workflows
        ├── __init__.py    <- Don't forget to add this
        └── hello.py       <- hello_world pipeline

    src layout

    Create a src/<package-name>/workflows directory and an empty __init__.py module inside it. Now copy the hello.py module from the previous example in the workflows/ folder. Finally, copy the following snippet inside the pyproject.toml file:

    pyproject.toml
    [tool.sdag]
dagdir = "src/<package-name>/workflows"

    Your project tree should look like this:

    src layout
    <package-name>
├── pyproject.toml
└── src
    └── <package-name>
        ├── __init__.py
        └── workflows
            ├── __init__.py    <- Don't forget to add this
            └── hello.py       <- hello_world pipeline

    Importing and running pipelines

    Now that everything is set up, you can list the available pipelines:

    sdag list

    you should see the hello_world pipeline available. You can run the pipeline through:

    sdag run hello_world --local

    If you don't like to specify --local every time, you can add it to the pyproject.toml:

    pyproject.toml
    [tool.sdag]
dagdir = "<flat-or-src-layout>/workflows"
local = true

    So that every task will be executed locally with bash.
